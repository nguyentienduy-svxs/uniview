check_circle 4 Mục hợp lệ (✓) warning 1 Cần bổ sung (⚠️)

Hệ thống rà soát tự động không chấm điểm năng lực. UniView hỗ trợ kiểm tra tính đầy đủ của bằng chứng (evidence) và quyền truy cập tệp/liên kết nhằm đảm bảo bài nộp của bạn sẵn sàng nhất trước khi chuyển sang bước phản tư và chấm theo Rubric.

priority_high

PHÁT HIỆN MỤC CHƯA HOÀN THIỆN: Bạn còn thiếu phần đề xuất cách sửa (Fix proposition / Code patch).

Đề xuất ít nhất 1 phương án sửa hàm tính tổng để người hướng dẫn có đầy đủ cơ sở đối chiếu.

1. Kiểm tra đủ bốn trường hợp (Test cases)

Đã hoàn tất kiểm thử và ghi nhận nhật ký cả 4/4 kịch bản luồng giỏ hàng: Áp mã voucher, đổi số lượng, hủy voucher, đơn giá 0đ.

check Đầy đủ ✓
TC01_VALID_VOUCHER: PASS TC02_CHANGE_QTY: PASS TC03_MAX_CAP: FAIL TC04_MIN_SUBTOTAL: FAIL

2. Xác định ít nhất một trường hợp có lỗi

Đã phát hiện 2 lỗi logic: Áp voucher giảm giá vượt quá trần quy định (giảm 85.000đ thay vì tối đa 50.000đ) và bỏ qua điều kiện giá trị đơn hàng tối thiểu khi đổi số lượng về dưới 200.000đ.

check Đầy đủ ✓

3. Giải thích nguyên nhân cốt lõi

Đã phân tích đoạn mã xử lý hàm reCalculateCartTotal(): thiếu validation middleware ở phía backend API khi cập nhật lại items.quantity và không clamp trần discount tối đa.

check Đầy đủ ✓

edit_note 4. Đề xuất cách sửa (Fix proposition / Code patch)

Hiện chưa có ghi chú phương án xử lý lỗi trong nhật ký. Vui lòng nhập nhanh giải pháp kỹ thuật bên dưới.

info Bạn cũng có thể đính kèm file .patch hoặc commit GitHub ở cột bên phải
